Conceptos y Tipos

Bases de Datos Relacionales (RDBMS)

Las bases de datos relacionales son sistemas que organizan la información en tablas formadas por filas y columnas,
las tablas pueden relacionarse entre sí mediante claves, lo que permite almacenar y consultar datos de forma estructurada. Un ejemplo puede ser MySQL

Bases de Datos no Relacionales (NoSQL)

Las bases de datos no relacionales (NoSQL) son sistemas que almacenan información sin utilizar necesariamente
tablas relacionadas como las bases de datos relacionales. Son más flexibles a la hora. Un ejemplo puede ser MongoDB

Estrutura de una base de datos relacional

Componentes Fundamentales

Para definir la estructura dentro de un modelo relacional se emplean los siguientes elementos

  • Tablas (Entidades): Estructuras donde se organizan los datos.
  • Campos (Atributos): Columnas que definen la tipología de información
  • Registros (Tuplas): Filas que contienen cada instancia concreta de datos.
  • Claves primarias (Primary Keys): Identificadores únicos de cada registro.

Relaciones entre tablas

Cardinalidades y Claves Foraneas

Las relaciones determinan como se vinculan las entidades entre si segun las reglas de negocio del sistema

  • Relación 1:1 (Uno a uno)
  • Relación 1:N (Uno a muchos)
  • Relación N:M (Muchos a muchos)

Una clave foranea es una clave que une tablas de la misma base de datos
